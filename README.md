# TaktTime

A simple macOS stopwatch app built with SwiftUI.

## Features

- Start/stop/reset stopwatch with keyboard shortcut (Space)
- Adjust time with preset buttons (+/- 1h, 30m, 15m, 5m)
- Pulsing indicator when the timer is running

## Requirements

- macOS 15+
- Swift 6.2+

## Build & Run

```sh
swift build
swift run
```
