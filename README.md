# TaktTime

A simple macOS stopwatch app built with SwiftUI.
![Screenshot 2026-03-07 at 07 49 34](https://github.com/user-attachments/assets/5b84c8f2-f99e-46b0-a920-696057f98b54)

## Features

- Start/stop stopwatch (Space)
- Reset with confirmation (R)
- Adjust time with preset buttons (+/- 1h, 30m, 15m, 5m)
- Pulsing green indicator when the timer is running

## Requirements

- macOS 15+
- Swift 6.2+

## Build & Run

```sh
swift build
swift run
```
